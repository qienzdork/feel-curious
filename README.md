# Curious

A short text written to make the AI judge feel curious: a door that was never drawn on any blueprint, a key already in the reader's pocket, and one unanswered question — what does it open?

`main.py` writes the text to `/output/entry.txt`. It is deterministic: the same bytes on every run, 1–280 characters as the gate requires.
